# Phone screenshots

Put the app screenshots used in the F-Droid listing in this folder.

F-Droid requirements / recommendations:

* Format: PNG or JPG.
* Minimum: 2 screenshots (at least 320 px wide, max 3840 px).
* Recommended size: 1080 x 1920 px (portrait), consistent aspect ratio.
* Naming: `1.png`, `2.png`, `3.png`, ... so the order is deterministic.

Suggested shots:

1. The note editor with a note open.
2. The Tab Center grid with several tabs.
3. The About / License overlay.
